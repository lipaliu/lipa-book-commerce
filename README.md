正式网址：https://lipa-book-commerce.lipaliu514.workers.dev

2026-10-06首版，独立Cloudflare Worker与D1部署。2026-10-06按用户要求取消项目访问码；网址打开直接进入共享工作台，无需账号、密码或会话Cookie。

## 已实现

- 工作概览、选品库、对标案例、内容工作台、制作队列、经营复盘、数据与设置。
- 真实历史资料：112个商品名称组、190份非教辅候选机器正文、7组有可用关联SKU成交观察。仍待人工逐条核实商品版本；名称组不是独立ISBN数量。
- 关键词、方向、收藏、成交画像与最新30天快照筛选；原视频和灰豚商品来源入口；完整机器正文和已有结构分析。
- Excel/CSV/JSON导入、教辅与知识服务强制过滤、重复文件防止重复入库；按视频ID保留参考与正文关联。
- 四种结构草稿模板；编辑、服务端保存、待素材队列、文本导出和任务归档。
- 按任务录入经营观察，未知指标保留空值；贡献栏只取各任务最新观察，避免把多个累计时点直接相加。
- 无访问码的共享工作台；资料、草稿和操作直接可用，写请求仍校验同源。
- 每天上海09:00的Cloudflare Cron；当前仅记录近30天数据入口检查与待采集状态。每日快照除汇总信息外，也保留当时的参考指标，不由下一次更新覆盖。

## 开发与部署

```sh
npm ci
python3 scripts/prepare_seed.py
npm test
npm run build
npx wrangler d1 execute lipa-book-commerce-db --local --file schema.sql
npx wrangler d1 execute lipa-book-commerce-db --local --file seed.sql
npm run dev
```

当前版本不使用APP_PASS或SESSION_SECRET，无需配置访问密码。初始化远端数据库同样执行schema与seed但使用`--remote`。已有数据库不能按新建环境任意清空。部署使用`npm run deploy`，线上秘密配置通过Wrangler secret stdin提交。

灰豚原文件、媒体、Obsidian原库及外接盘不会因网站部署而删除。网站只部署非教辅候选正文与必要元数据，未把约15GB原始视频上传到云端。

## 成交依据与开头选择（2026-10-06）

内容简报按具体参考记录和SKU绑定成交依据。性别、年龄选项只使用已核对成交页保存的实际比例，并提供“不限定”；边际分布不合成为交叉占比。当前7款可用画像仅保存主要性别与最大年龄组，画像周期、样本量、职业和原生八大人群缺失，不补造。缺少画像或参考正文时暂不生成。

购买任务、制作模板和素材计划根据对应参考正文及已有结构分析提供选项，标记为内容假设。素材计划保持“待补”，不冒充已获得书页。开头每个任务提供5个原创候选句和1个自由填写项；选自由项后展开输入框，留空则采用问题开头。当前候选为结构规则生成，尚未通过转化测试，不是5条独立高转化证据。

服务器重新解析选项ID、SKU和源版本，不信任前端传入的人群文案或百分比；任务保存选择与来源，排队时再次核验。旧稿可以继续阅读、编辑、导出，进入待素材队列前需要补齐本次有效选项。

## 视频制作流程（2026-10-07）

制作队列的“分镜与素材”打开完整流程：文案定稿 → 对标拆解 → 取舍与优化 → 分镜编排 → 图/漫画/视频选择 → VO与字幕 → 模型任务 → 串联试片。先确认VO，再准备模型请求；文案和镜头选择分别保留，可改文字、画面想法、增删镜头，成片目标15或30秒。每个镜头提供3张构图示意，示意图明确标为非模型出图。实际图卡可下载PNG/SVG，整体可导出ZIP。修改稿件或选择会使旧模型请求与媒体失配，必须使用新方案。

《中国神仙》补做本地原视频12个时点抽帧审核，仅证明这些位置的可见包装、翻页、目录与图版。未把抽帧说成完整逐镜头边界检测。其他参考只有正文和结构卡时，画面状态继续保持未审核。

目前的视频模型接入按官方API实现：Seedance创建/查询任务、MiniMax H3创建/查询任务；接口参数和状态处理有模拟响应测试，尚未用真实视频模型账号验证。用户明确不要模型CLI中转，LibTV/Higgsfield CLI不会承担网站生成执行。公开工作区只准备请求，模型额度执行端用服务器侧令牌保护，凭证不进入前端。未确认的提交不会自动重试，避免重复消耗额度。

图片与中文旁白测试使用既有Cloudflare Workers AI绑定：FLUX.2 klein-4B图片、MeloTTS中文旁白（实际返回WAV，按文件头识别格式）。使用官方包含的免费测试额度，设置应用每日测试量上限（图片保留200单位、旁白25单位，合计1200；这是应用测试预算单位，不是实时神经元账单）。不升级套餐或启用付费视频服务，超限失败不会自动切换付费。Cloudflare账户额度由该账户所有应用共享。

确认文案后可生成选中场景图片、中文旁白，保留真实媒体字节；素材按方案版本缓存。浏览器把选中图卡/已生成图片和旁白录制为15/30秒竖屏试片，支持下载；编码器可用时MP4，否则WebM。不是Seedance/MiniMax动态场景成片，也不假称已有真实书页、完整字幕强制对齐或已发布抖音。真实实物/书页/录屏依然单独列出。

## 本次实际验收（2026-10-07）

34个单元与接口契约测试通过；本地16项API检查、公网8项API检查通过。浏览器实际完成15秒与30秒中文VO试片，下载文件并解码为720×1280、H.264视频与Opus音频。30秒文件约2.33MB，真实时长30.02秒；保存到D1后支持匿名播放、下载及206字节范围请求。WAV音频分块保存，兼容旧版单条base64记录，避免D1单值限制。当前是浏览器试片，不代表所有发布平台已接受此编码。

视频API接入后会使用选中已生成图片作为首帧，成功返回的片段经受限域名代理进入镜头串联；该路径目前有契约测试，尚未进行真实Seedance或MiniMax生成。
